# Hermes 기능 현황

기준: [Hermes Agent 공식 기능 개요](https://hermes-agent.nousresearch.com/docs/user-guide/features/overview). 아래는 Naru 기능에 관한 현황이며, Hermes 자체를 통합했다는 뜻이 아닙니다.

| 기능 | Naru의 현재 상태 |
| --- | --- |
| 모델 제공자, 로컬 서버 | 여러 계정 CLI와 API, Ollama·LM Studio 연결. 서버와 모델에 따라 기능 차이 있음. |
| 도구, 파일, 터미널, 웹 검색 | 기본 도구 제공. 쓰기·수정·명령은 Naru 승인 필요. 일부 Hermes 도구와 실행 환경은 미지원. |
| 대화 검색 | 사용자가 요청한 이전 대화 검색에 매번 승인 필요. 승인한 발췌는 현재 모델에 전달. |
| 작업 계획 | 실행별 작업 목록 저장 및 중단된 실행 재개 시 복원. |
| 메모리, 스킬 | 명시적으로 저장하는 메모리와 사용자 스킬 지원. Hermes의 학습·스킬 허브·외부 메모리 제공자와는 다름. |
| 실행 이력, 중단 및 재개 | Naru 실행 이벤트와 도구 승인 기록, 재개 지원. Hermes 체크포인트/전체 작업 폴더 롤백은 미지원. |
| 브라우저 | 검색·페이지 읽기 지원. Hermes의 모든 상호작용 및 브라우저 백엔드는 미지원. |
| 예약, 서브에이전트, MCP, 훅 | 미지원. |
| 음성, 이미지 생성·분석, 메신저 연동 | 미지원. |
| 공급자 자동 대체, 키 풀, 배치, API 서버, IDE/ACP | 미지원. |

이 Mac에 Hermes CLI가 설치되어 있어도 Naru와 자동으로 통합되지 않습니다. Hermes의 일괄 실행 모드는 승인 절차를 우회하므로 Naru에서 임의로 실행하지 않습니다. 기능별 실행 권한과 사용자 확인을 연결하고 실제 동작을 검증하기 전에는 완전한 호환을 주장하지 않습니다.
