# Naru 검증 기록

## 0.2.0 — 2026-10-29

### 자동 검증 (이 Mac의 실제 providers.py 기준)

- Python unittest 47개 통과: 모델 프로토콜, 실행 흐름, 안전 경계, 0.2 기능(edit_file, 덮어쓰기 확인, 파일 검색, 모두 허용, 답 다시 받기, 스트리밍 버퍼, 본문 검색, JSON 인덱스, 계정 계획 검증, Claude CLI 격리, OpenRouter state 검증).
- 데스크톱 보안 테스트 4개 통과: 외부 URL, 경로 정규화, 기본 앱으로 열기 허용 형식(심볼릭 링크는 실제 대상 기준), IPC 발신자 출처.
- UI 렌더링 검사 통과: HTML 이스케이프, 안전한 링크만 연결, 코드·표, 스트리밍 중 코드 블록, 줄 비교, 첨부 분리, 도구 단계 짝짓기.

### 끝에서 끝까지

- OpenAI 호환 가짜 서버를 실제 providers.py로 연결: 모델 목록 → 스트리밍 답변과 토큰 사용량 → 에이전트 write_file 승인 → 파일 생성과 결과물 등록 → 답 다시 받기 → 본문 검색.
- 기존 `data/` 사본으로 0.2 서버를 띄워 대화 2개, 실행 기록, 연결 3개, 스킬 2개가 그대로 열리고 새 인덱스가 생기는 것을 확인했습니다. 원본 데이터는 건드리지 않았습니다.

### 화면 (Chromium, 1440×920 · 390×844)

- 첫 화면 HeroHorizon WebGL2 렌더링, 대화·스트리밍·승인·거절·오류·재시도, 모델 메뉴, 단계 펼치기, 파일 패널과 미리보기, 검색 팔레트, 모델·스킬·메모리·설정, 연결 추가, 다크 모드, 모바일 사이드바를 스크린샷으로 확인했습니다. 콘솔 오류 없음, 모바일 가로 넘침 없음.
- 사용자 흐름 17개 자동 통과: 답변 도중 화면 갱신, 답 다시 받기, 코드 복사, 오류 후 재시도, 모두 허용, 제목으로 이름 바꾸기, 파일 첨부, 본문 검색, Claude 계정 연결과 대화, Gemini 로그인 전 전송 차단, 메모리·스킬, 연결 추가와 확인, 테마, 설정 저장, 대화 삭제, 단축키.
- 화면 증거는 개인정보 보호를 위해 GitHub 저장소에서 제외하고 로컬 docs 폴더에 보관합니다.

### 검증하지 못한 것

- macOS 창 비브런시(사이드바 반투명)와 알림은 Linux에서 확인할 수 없어 실제 Naru.app에서 직접 보셔야 합니다.
- Claude·Gemini·Copilot 계정 연결은 CLI 출력 형식 테스트로 검증했고, 이 Mac에 해당 CLI 로그인이 없어 실제 계정 응답은 확인하지 않았습니다. OpenRouter OAuth는 요청 생성과 state 검증까지 확인했습니다.
- Ollama·LM Studio 실제 로컬 추론은 서버가 실행 중이 아니어서 확인하지 않았습니다.
- Codex 데스크톱 앱이나 Hermes Agent와의 비교 벤치마크는 하지 않았습니다.

## 0.1.0 — 2026-10-29

- Python unittest 36개, 데스크톱 보안 테스트 3개 통과. 공식 Codex CLI의 기존 ChatGPT 로그인으로 실제 응답과 에이전트 파일 생성 확인. 패키징된 Naru.app 재실행 후 대화 복원 확인.

## 2026-10-29 추가 검증

- Claude의 ego(lite) Style 아티팩트 본문이 캡처된 18:10 작업 이력을 확인하고 현재 CSS와 비교했습니다. 현재 라이브 아티팩트 본문은 열리지 않아 이력에 남은 원본 기준으로 검증했습니다. 모델 팝오버의 보조 글자 크기를 원본 규칙에 맞게 14px/20px로 수정했습니다.
- ChatGPT의 Codex app-server에서 실제 모델 4개를 불러왔고, 선택과 로컬 서버 오프라인 표시를 분리된 브라우저 데이터로 확인했습니다. 화면 증거는 로컬에 보관합니다. 카탈로그는 실제 모델 사용 권한 보장이 아닙니다.
- Python 테스트 53개, 데스크톱 보안 테스트 4개, UI 상호작용과 모델 자동 탐색 검사 통과. 이전 대화 검색의 승인·거절 및 작업 목록 저장 검사 포함.
- Hermes 전체 기능은 미지원이며 `HERMES-COMPATIBILITY.md`에 현재 범위를 기록했습니다.

## 0.2.1 — 2026-10-29

- Python 단위 테스트 86개와 데스크톱 보안·UI 테스트 통과: 접근 권한의 기본값과 저장, 새 실행에 대한 설정 적용, 중단된 실행의 재승인, 파일 경계, 취소, 모델 스트림, 재생성, 웹 주소 검사와 Git 조회를 포함합니다. 공급자 프로토콜 중 상당수는 가짜 응답으로 검증했습니다.
- 격리된 임시 데이터에서 OpenAI 호환 테스트 서버를 이용해 모델 도구 호출 → 승인 → 파일 생성 → 응답 저장을 검증했습니다. 별도의 격리 세션에서 이 Mac의 기존 ChatGPT/Codex 로그인으로 실제 응답을 받았습니다.
- Ego Lite를 통한 검색이 실제 결과를 반환하는 것을 확인했습니다. Claude AI는 사용하지 않았고 Gemini·Copilot CLI 실행, 실제 Ollama·LM Studio 추론은 검증하지 않았습니다.
- Hermes의 예약, 서브에이전트, MCP 및 기타 미지원 기능은 테스트 통과로 간주하지 않습니다. 상세 비교는 `HERMES-COMPATIBILITY.md`를 참조하세요.

- 분리된 브라우저 환경에서 모델 연결 추가, 연결 확인, 모의 모델과의 대화, 밝은 테마 및 권한 설정 저장을 직접 확인했습니다. 알림 권한 창에서 사용자 제어로 전환되어 에이전트·메모리·스킬의 나머지 UI 흐름은 직접 확인하지 못했습니다.
- 움직임의 첫 시안은 브라우저에서 시간에 따른 픽셀 변화를 확인했습니다. 이후 큰 점의 기존 SVG를 사용하도록 바꾼 최종 시안은 사용자 제어 전환으로 브라우저에서 시각 재검증하지 못했습니다. 디자인 시스템 HalftoneField 원본 구현은 발견하지 못했습니다.

## 0.2.2 — 2026-10-29

- 사용자의 로컬 브라우저 캐시에서 ego(lite) 디자인 시스템의 HalftoneField 번들을 확인해 셰이더를 적용했습니다. Naru에 맞게 밝은 테마 출력과 수명주기 처리를 덧붙였습니다.
- 격리된 앱 데이터로 실제 macOS Naru 창에서 어두운 테마의 움직임과 포인터 렌즈, 밝은 테마의 배경·점·제목 색을 확인했습니다. 가독성 마스크 조정 후 밝은 테마를 다시 확인했습니다.
- Hermes ACP는 격리된 임시 홈에서 초기화 응답을 확인했습니다. Naru에 Hermes 엔진이 연결된 것은 아닙니다.

## 0.2.3 — 2026-10-29

- OpenRouter의 IPv4 콜백과 PKCE 상태값을 적용하고, 격리된 로컬 서버에서 모의 코드 교환과 재사용 방지를 검증했습니다. 공개 모델 목록 조회는 성공했으나 실제 계정 인증과 추론은 검증하지 않았습니다.
- Gemini 모델 목록 페이지네이션, 오프라인 로컬 서버 안내, 모델 목록 오류 표시를 테스트했습니다. 이 Mac의 Ollama·LM Studio는 서버가 실행 중이지 않습니다. Gemini·Copilot CLI의 도구 격리는 검증되지 않아 연결 차단을 유지합니다.

## 0.2.4 — 2026-10-29

- 이 Mac에서 사용자가 OpenRouter 연결을 승인한 뒤 인증된 모델 목록을 확인했습니다. 실제 무료 모델 요청에서 Liquid와 Gemma, NVIDIA Nemotron 각각의 응답 model 필드가 요청한 모델 ID와 일치하는 것을 확인했습니다. 이는 제공자가 보고한 ID이며 내부 실행 환경의 독립적인 증명은 아닙니다. Claude AI는 사용하지 않았습니다.
- 요청 모델이 실행 문맥에 전달되고, OpenAI 호환 응답이 모델 ID를 반환할 때 실행 기록과 화면에 요청 모델과 분리해 표시하는 테스트를 추가했습니다. 과거 실행에는 당시 응답 ID가 없을 수 있습니다.
